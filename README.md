## About

Bd ProTech is an independent Android app publisher. The apps are small, fast and focused: a lightweight web browser,
a score counter, a chess clock and a data usage monitor. All apps are built natively for Android.

## What is in this repository

This repository is the GitHub Pages site of Bd ProTech.

- `index.html`, `404.html`, `robots.txt`, `sitemap.xml` — the landing page and its SEO files
- `windbrowser/`, `scoreboard/`, `chessclock/`, `networkmanager/` — privacy policy pages of the apps
- `wavy/` — pages of Wavy: Music Player (privacy policy, update info)
- `windplayer/` — files of the earlier Wind Player (the app is now called Wavy)
- `app-ads.txt` — authorized sellers file for in-app advertising
